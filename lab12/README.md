# Лабораторная работа 12. Итоговый проект

*Автор:* Мохамед Траоре
*Вариант:* 9 — План задач по программированию
(amount — количество баллов, completed — задача решена)

## Назначение
Консольная программа для учёта задач по программированию:
просмотр, добавление, поиск, изменение статуса, удаление,
статистика и сохранение данных в JSON.

## Версия Python
Python 3.x (укажите свою версию: python --version).
Внешние библиотеки и интернет не нужны.

## Запуск
python main.py

## Тесты
python -m unittest test_logic -v
python -m unittest test_storage -v

## Файлы
- main.py — меню, ввод и сообщения
- logic.py — проверка записей, добавление, поиск, статус,
  удаление, статистика
- storage.py — чтение и запись JSON
- test_logic.py, test_storage.py — автоматические тесты
- data.json — небольшой вымышленный набор данных

## Формат данных (data.json)
Список записей. Каждая запись — словарь с пятью ключами:
- id — положительное целое, уникальное;
- title — непустая строка;
- category — непустая строка;
- amount — целое число не меньше 0 (баллы);
- completed — true или false.

Пример:
{"id": 1, "title": "Сумма чисел", "category": "циклы",
 "amount": 3, "completed": true}

## Сценарии приёмки
| Сценарий | Ожидаемое поведение | Результат |
|---|---|---|
| Файла нет | Пустой список, меню доступно | |
| JSON содержит [] | Все количества и сумма равны 0 | |
| Записи 4 и 2, вторая решена | Всего 2, решена 1, не решена 1, сумма 6 | |
| Название « Python » | Сохранено «Python» | |
| Поиск PY при названии Python | Запись найдена | |
| Пустое название, -1, abc | Повторный ввод, записи нет | |
| Статус неизвестного ID | Сообщение, данные не изменены | |
| Удаление отменено | Запись сохранена | |
| Удалена запись 1 из списка 1 и 2 | Остаётся ID 2, новая получает ID 3 | |
| Сохранение и перезапуск | Все поля и статусы восстановлены | |
| Повреждённый JSON или повторный ID | Запуск прекращён, файл не изменён | |
| Ошибка сохранения | Нет сообщения об успехе | |

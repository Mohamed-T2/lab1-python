## Задание 3. Предскажите результат

| Выражение | Прогноз | Результат Python |
|---|---|---|
| 2 + 3 * 4 | 14 | 14 |
| (2 + 3) * 4 | 20 | 20 |
| 17 // 5 | 3 | 3 |
| 17 % 5 | 2 | 2 |
| -7 // 2 | -4 | -4 |

Различий между прогнозом и результатом нет. Умножение выполняется раньше сложения, скобки меняют порядок действий. Оператор // округляет вниз, поэтому -7 // 2 равно -4, а не -3.

### Объяснение операторов

- / — обычное деление.
- // — целочисленное деление с округлением вниз.
- % — остаток от деления.

Форматирование числа не устраняет погрешность его внутреннего представления с плавающей точкой.

### Задание 2. Статистика чисел

Программа вводит n целых чисел и вычисляет:
- сумму всех чисел;

программа повторяет запрос.

выводит его квадрат и количество отклонённых попыток.
